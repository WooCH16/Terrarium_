# 정리본 경로

규칙 원문은 CLAUDE.md(규칙: "정리본 경로 (큰 작업)", "승인 규칙")에 있다.

## 순서

1. 브레인스토밍으로 요구를 다듬는다. 이 동안에는 이슈도 하달도 없다.
2. 질문이 끝나면 **"보고서로 만들까요?"** 라고 묻는다.
3. 정리본(목표, 범위, 완료 기준, 가정)을 쓴다. 완료 기준은 `| 기준 | 확인 방법 |` 두 열이다(규칙: "완료 기준의 형식").
4. 기록 문서에 승인 대기 초안을 적고 커밋·푸시한다(`coordinator-records`).
5. 승인을 요청한다. 승인으로 보는 말은 "승인", "진행해", "좋아", "그대로 해", "OK", "ㅇㅋ"뿐이다. 애매하면 "이대로 진행해도 될까요?"라고 한 번 더 묻는다. 승인은 가장 최근 버전에만 적용한다.
6. 승인되면 `coordinator-direct`의 4번(조언)부터 이어 간다. 승인이 곧 분해의 시작이다.

## 확인할 점

- 승인 전에는 분해하지 않는다.
- 승인본이 있는데 요구가 바뀌면 새 버전(vN+1)을 만들어 다시 승인받는다.
