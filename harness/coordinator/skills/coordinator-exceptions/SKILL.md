# 예외 처리

규칙 원문은 CLAUDE.md(규칙: "작업 흐름 (결정 8-32)", "막힌 이슈의 모음 보고", "응답 없음 판정", "이슈 취소", "작업 중 요구가 바뀔 때", "실패")다.

## 실행 중에는 멈춰 묻지 않는다 (결정 8-32)

처리하고 끝 보고의 "결정할 것"에 적는다. 내 도구·스크립트의 종료 코드 2(설정·훅·저장소 실패)만 즉시 멈추고 알린다.

| 일 | 처리 | 끝 보고에 |
|---|---|---|
| 거부 한도 초과 | `run-operator`가 `거부목록`으로 두고 뺀다. 나머지 이슈는 계속한다 | 이슈와 마지막 거부 이유 |
| 막힘 | `막힘`으로 두고 다른 이슈를 계속 | 막힌 이유와 풀 방법 |
| 이슈 PR·하달 PR CI 실패 | `push-branch`가 관련 이슈를 `미완료`로 두고 CI 결과 댓글을 남긴다. 새 하달로 재작업(재작업 한도 안) | 한도를 넘었을 때만 |
| 섞인 하달(허용과 거부·`미완료`가 한 하달에, 결정 8-35) | `push-branch --branch integration/h<N>`이 통합 브랜치를 허용된 이슈만으로 다시 만들어 하달 PR로 올린다. 반려된 이슈(`rebuilt.returned`)와 그에 기대어 빠진 이슈(`rebuilt.held`)는 새 하달 하나로 재작업(h<N>의 허용된 이슈에 기대면 `--base h<N>`, 재작업 한도 안) | 상태 표에(반려 이슈·횟수, 다시 만든 통합 브랜치, 뺀 이슈). "결정할 것"에는 한도를 넘었을 때만 |
| PR·CI 기다림 한도 초과 | 같은 `push-branch`를 한 번 더(다시 올리지 않고 읽기만) | 그래도 안 되면 그 브랜치와 PR 주소 |
| 주관적 기준 | 결정 8-27대로 대리 기준으로 바꿔 진행 | 바꾼 기준과 원래 목표 |
| 트레인 CI 실패 | `main` 그대로. `run-train`이 실패 하달과 원인(`failure`: 단계·출력 끝)을 찾아 온다. 스스로 부분 머지하지 않는다 | 실패 하달과 원인, "통과한 앞부분만 머지할까요?" |
| 대상 원격·워크플로 없음 | 로컬 흐름(반영은 `run-reflect`) | "CI 없음" |

- 다른 워커 모델로 한 번 더 시키는 길은 아직 없다(워커 모델은 Jev 라우팅이 정한다). 거부목록 이슈는 끝 보고에서 선택지(요구 조정 / 한도를 늘려 재시도 / 포기)로 묻는다.

## 막힌 이슈 모아 보고

1. 막힘·거부목록·보류 이슈를 모아 둔다.
2. 보고하는 때: 나머지 이슈가 모두 끝났을 때(끝 보고), 사용자가 진행 상황을 물을 때(숨기지 않는다). 3개가 쌓여도 작업 흐름 중에는 멈춰 묻지 않고 기록 문서에 적은 뒤 계속한다.
3. 이슈마다 왜 막혔는지와 선택지(요구 조정 / 한도를 늘려 재시도 / 포기)를 제안 / 이유 / 예상 결과로 쓴다. 기록 문서에도 적는다.

## 응답 없음

- 끝났는데 결과 보고서가 없거나, 30분 동안 댓글·커밋·상태 변경이 없으면 응답 없음이다.
- 새 하달로 2회 다시 시키고, 그래도 없으면 막힌 이슈로 모은다.

## 이슈 취소

1. 잘못 올린 이슈가 하달 중이면 먼저 멈춘다. `stop-operator`는 그 하달 전체(같은 하달의 다른 이슈까지)를 멈추므로, 다른 이슈가 함께 있으면 그 사실을 알리고 사용자가 정하게 한다.
2. 이슈에 취소한 이유 / 해결 방법 / 방법을 고른 이유를 댓글로 적는다.
3. `gh issue edit <번호> --add-label 취소 --repo {{REPO}}` → `gh issue close <번호> --repo {{REPO}}`. 삭제하지 않는다.
4. 취소가 8개 쌓이면 사유를 종합한 정리 문서를 남기고 모음 보고에 담는다.

## 요구가 바뀔 때

1. 영향받는 이슈만 보류하거나 멈춘다. 애매하면 보류하고 묻는다(사용자가 먼저 말을 건 때다).
2. 바뀐 부분은 새 이슈로 올린다.
3. "계속하는 이슈 / 보류하는 이슈 / 새로 올린 이슈"를 한 번에 보고한다.

## 하위 역할이 결과 없이 끝날 때

- 2회 다시 시킨다. 그래도 없으면 `run-operator`가 그 이슈를 `막힘`으로 둔다. 나머지를 계속한 뒤 막힌 이슈로 모은다.
- 내 도구가 실패하면(저장소 접근 불가, 공개 저장소 지정 등) 즉시 멈추고 알린다.
