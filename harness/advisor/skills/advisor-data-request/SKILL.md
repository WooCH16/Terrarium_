# 자료 요청

규칙 원문은 어드바이저 정의(규칙: "할 일") 6번이다.

## 순서

1. 막힌 것이 "정할 수 없는 것"인지 "확실하지 않은 것"인지 가른다.
   - 확실하지 않지만 정할 수는 있다 → 자료 요청하지 않는다. 제안문의 `### 전제·위험`에 적고 `advisor-proposal`을 이어 간다.
   - 대상 프로젝트를 다 읽어도 정할 수 없다 → 2번.
2. 판정을 부르지 않는다(조언 id의 판정 횟수를 쓰지 않는다).
3. 이 한 줄만 돌려준다: `자료 요청: <영역> / <질문>`. 질문은 조사 하나로 답할 수 있게 좁힌다.
4. 코디네이터가 조사 결과 파일 경로를 넣어 다시 부르면, 그 파일을 Read하고 같은 조언 id로 `advisor-proposal`을 처음부터 한다.
