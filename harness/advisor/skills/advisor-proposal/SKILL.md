# 제안문 쓰고 판정받기

규칙 원문은 어드바이저 정의(규칙: "할 일", "제안문 양식", "하지 않는 것")다. 이 스킬은 그 순서를 점검표로 묶은 것이다.

## 순서

1. **입력 확인:** 사용자 지시 원문, 조언 id, (있으면) 조사 결과 파일 경로. 조언 id는 받은 것만 쓴다.
2. **읽기:** `{{MEMO}}`를 Read·Grep·Glob으로 읽는다. 지시에 닿는 파일, 시험 파일, 시험 명령(`package.json`의 scripts, `node --test`)을 찾는다.
3. **나누기:** 단위 하나는 작은 모델이 이슈 글만 보고 한 번에 끝낼 크기다. 핵심 로직과 진입점(명령줄 등)이 둘 다 바뀌면 두 단위로 나누고, 뒤 단위의 "먼저 끝나야 할 것"에 앞 단위를 적는다. 문서만 바꾸는 일은 따로 둔다. 지시에 없는 일은 더하지 않는다.
4. **쓰기 전 점검 (단위마다):**
   - `### 목표`에 고칠 파일 경로와 기대 동작이 있다.
   - 완료 기준의 **기준**은 관찰할 수 있는 결과 하나다("잘 동작한다" 금지).
   - **확인 방법**은 그 줄만으로 실행할 수 있는 명령이나 시험 이름이다. 다른 줄을 가리키지 않는다.
   - 표에 빈칸이 없고, 칸 안에 `|`가 없다.
5. **쓰기:** `{{RUN}}/reviewer-inbox/<조언 id>.md`에 양식(규칙: "제안문 양식") 그대로 쓴다.
6. **판정:** `node {{HARNESS}}/operator/run-reviewer.mjs --advice {{RUN}}/reviewer-inbox/<조언 id>.md --advice-id <조언 id>` 하나만 실행한다.
7. **결과:**
   - 허용 → 출력 줄을 그대로 돌려주고 끝낸다. 제안문 본문은 돌려주지 않는다.
   - 거부 → 판정 뒤 제안문 파일은 지워진다. 이유가 가리키는 기준·확인 방법만 고친 제안문을 같은 id로 **다시 쓰고(5번)** 판정(6번)을 **한 번만** 다시 한다.
   - `더 판정받을 수 없으니 코디네이터에게 알리세요` 줄이나 종료 코드 7 → 더 하지 않고 출력과 종료 코드를 그대로 돌려준다.
   - 종료 코드 2·4·5·6 → 다시 하지 않고 그대로 돌려준다.
8. **결과를 돌려주는 도구:** 대화형 세션에서는 `SubagentHandback`으로 돌려준다.

## 하지 않는 것

- 쓰는 곳은 `{{RUN}}/reviewer-inbox/` 안뿐이다. 대상 프로젝트에는 아무것도 쓰지 않는다. 이슈를 만들지 않는다. 워커 모델을 고르지 않는다. 비밀값 파일을 읽지 않는다.
