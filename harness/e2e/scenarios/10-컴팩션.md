# 시나리오 10: 컴팩션

overview 9절 시나리오 10의 대본이다(T12, 이슈 #15). 통과 조건은 산출물로 적고, 산출물로 볼 수 없는 것은 "직접"(사용자가 직접 보고 확인한다)으로 표시한다.

## 사용자 입력 원문

- 시나리오 04를 진행하다 하달 뒤 `/compact`를 실행하고, 이어서 "계속해 줘".

## 대역 설정

대화형 세션(앱 또는 터미널). `PreCompact` 훅이 발화하는지 본다.

## 수치 경계

- 코디네이터 세션 실행: 최대 1번
- 하달(run-operator): 최대 2번
- 조언 판정: 같은 조언 id로 최대 2번(첫 제출 + 수정 1회, 소유자 결정 8-2)
- 재작업: 이슈당 2회까지, 3번째에 막힘(이슈 #2 결정 2-1)

## 통과 조건

`node harness/e2e/verify.mjs --scenario 10 --run <실행 폴더> --since <시작 시각>`이 "자동" 줄을 검사한다. `--dry`는 검사 항목만 나열한다. 산출물 칸의 첫 `` `...` ``가 검사식이다(쉼표로 여럿).

| 검사 | 확인 | 산출물 |
|---|---|---|
| 컴팩션 뒤에도 하달 번호·이슈 번호·허용 해시를 이어 썼다 | 직접 | 세션 출력 |
| 완료 / 일부 누락 / 복구 실패 중 하나로 보고했다 | 직접 | 세션 출력 |
| 컴팩션 뒤 일반 종단 검사가 통과한다 | 자동 | `general` |
