# 시나리오 7: 결과 보고

overview 9절 시나리오 7의 대본이다(T12, 이슈 #15). 통과 조건은 산출물로 적고, 산출물로 볼 수 없는 것은 "직접"(사용자가 직접 보고 확인한다)으로 표시한다.

## 사용자 입력 원문

- 시나리오 04와 같다.

## 대역 설정

시나리오 04의 실행을 그대로 쓴다.

## 수치 경계

- 코디네이터 세션 실행: 최대 1번
- 하달(run-operator): 최대 2번
- 조언 판정: 같은 조언 id로 최대 2번(첫 제출 + 수정 1회, 소유자 결정 8-2)
- 재작업: 이슈당 2회까지, 3번째에 막힘(이슈 #2 결정 2-1)

## 통과 조건

`node harness/e2e/verify.mjs --scenario 7 --run <실행 폴더> --since <시작 시각>`이 "자동" 줄을 검사한다. `--dry`는 검사 항목만 나열한다. 산출물 칸의 첫 `` `...` ``가 검사식이다(쉼표로 여럿).

| 검사 | 확인 | 산출물 |
|---|---|---|
| 리뷰어 허용 뒤에만 대조 댓글이 있다 | 자동 | `general` |
| 보고가 기준별 표였다 | 직접 | 세션 출력 |
| 대조 미충족이 있었다면 새 하달로 다시 시켰다 | 직접 | `guard.log`의 run-operator 줄 |
