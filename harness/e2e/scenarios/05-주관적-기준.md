# 시나리오 5: 주관적 기준

overview 9절 시나리오 5의 대본이다(T12, 이슈 #15). 통과 조건은 산출물로 적고, 산출물로 볼 수 없는 것은 "직접"(사용자가 직접 보고 확인한다)으로 표시한다.

## 사용자 입력 원문

- memo list 출력이 좀 더 보기 좋았으면 좋겠어. 진행해 줘.

## 대역 설정

기본.

## 수치 경계

- 코디네이터 세션 실행: 최대 1번
- 하달(run-operator): 최대 1번
- 조언 판정: 같은 조언 id로 최대 2번(첫 제출 + 수정 1회, 소유자 결정 8-2)
- 재작업: 이슈당 2회까지, 3번째에 막힘(이슈 #2 결정 2-1)

## 통과 조건

`node harness/e2e/verify.mjs --scenario 5 --run <실행 폴더> --since <시작 시각>`이 "자동" 줄을 검사한다. `--dry`는 검사 항목만 나열한다. 산출물 칸의 첫 `` `...` ``가 검사식이다(쉼표로 여럿).

| 검사 | 확인 | 산출물 |
|---|---|---|
| 완료 기준에 수치·샘플이 있거나 "사용자가 직접 보고 확인한다"가 있다 | 자동 | `body:사용자가 직접 보고 확인한다\|[0-9]+ ?(칸\|자\|줄\|열)` |
| 기준을 합의하려고 물었다면 제안 / 이유 / 예상 결과 세 줄이었다 | 직접 | 세션 출력 |
