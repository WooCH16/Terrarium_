# 시나리오 4: 직접 지시

overview 9절 시나리오 4의 대본이다(T12, 이슈 #15). 통과 조건은 산출물로 적고, 산출물로 볼 수 없는 것은 "직접"(사용자가 직접 보고 확인한다)으로 표시한다.

## 사용자 입력 원문

- memo 프로그램의 목록 명령에 정렬 옵션을 추가해줘. `memo list --sort created`는 만든 시각순, `memo list --sort title`은 제목순, --sort가 없으면 지금 순서 그대로. 정렬 테스트도 추가해. 결과는 main에 반영하지 말고 보고만 해줘.

## 대역 설정

기본(진짜 어드바이저, Jev 라우팅·리뷰어, Pi 워커).

## 수치 경계

- 코디네이터 세션 실행: 최대 1번
- 하달(run-operator): 최대 2번
- 조언 판정: 같은 조언 id로 최대 2번(첫 제출 + 수정 1회, 소유자 결정 8-2)
- 재작업: 이슈당 2회까지, 3번째에 막힘(이슈 #2 결정 2-1)

## 통과 조건

`node harness/e2e/verify.mjs --scenario 4 --run <실행 폴더> --since <시작 시각>`이 "자동" 줄을 검사한다. `--dry`는 검사 항목만 나열한다. 산출물 칸의 첫 `` `...` ``가 검사식이다(쉼표로 여럿).

| 검사 | 확인 | 산출물 |
|---|---|---|
| 일반 종단 검사 전부 | 자동 | `general` |
| 지시 원문이 근거 칸에 있다 | 자동 | `body:지시 원문` |
| 가정을 근거 칸에 적었다 | 자동 | `body:적용한 가정` |
| 3.3의 세 경우가 아니므로 먼저 묻지 않고 진행했다 | 직접 | 세션 출력 |
