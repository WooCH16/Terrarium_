# Terrarium

Terrarium은 Claude Code 에이전트를 계층으로 나눠 일을 맡기는 개인용 하네스입니다. 사용자는 코디네이터 한 명과만 대화합니다.

| 역할 | 하는 일 |
|---|---|
| 코디네이터 | 사용자와 대화하고, 요구를 정리해 승인받고, 작업을 이슈로 쪼개 하달하고, 결과를 대조해 보고합니다. |
| 어드바이저 | 영역 지식으로 작업 분해 제안문을 씁니다. 조언만 합니다. |
| 오퍼레이터 | 이슈를 받아 팀을 운영하고 보고서를 씁니다. 별도 세션입니다. |
| 워커 | 실제 작업을 합니다. Pi로 돌리며, 작업마다 워크트리 하나를 씁니다. |
| 리뷰어 | 보고서를 허용/거부합니다. Pi로 돌리고, 읽기 전용이며 판정 형식이 고정되어 있습니다. |

결과는 오퍼레이터 보고서 → 리뷰어 허용/거부 → 코디네이터 완료 기준 대조 → 사용자 보고 순서로 올라옵니다. 자세한 정의는 [docs/00-definition.md](docs/00-definition.md)를 봅니다.

## 현재 상태

- **구현된 것:** 관제탑 화면입니다. 오케스트라 대화, 팀 상세, 통합, 사무실 네 가지 뷰가 있고, 데이터는 `js/api.js`의 목(mock)입니다. 실제 에이전트와는 연결되어 있지 않습니다.
- **설계만 있는 것:** 코디네이터, 어드바이저, 오퍼레이터, 워커, 리뷰어의 동작은 문서(`docs/`)로만 있습니다. 하네스 실행 코드는 이 저장소에 없습니다.
- **검증 전:** Pi로 워커와 리뷰어를 돌리는 방식은 ADR 0004(제안됨)에 있고, 시험 계획 6단계가 아직 하나도 실행되지 않았습니다.

## 관제탑 화면 실행

빌드 없이 정적 파일로 동작합니다. `index.html`을 브라우저로 열면 됩니다.

- 오케스트라 입력창에 "보안팀 일시정지", "디자인 작업 시작", "전체 대기"처럼 팀 이름과 동작을 쓰면 목 백엔드가 상태를 바꿉니다.
- 왼쪽 사이드바에서 매트릭스/사무실 뷰와 팀별 화면을 전환합니다.
- 화면은 880×600을 기준으로 만들었고 창 크기에 맞춰 확대·축소됩니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html`, `css/`, `js/`, `assets/` | 관제탑 화면 (`js/api.js`는 목 백엔드, `assets/`는 픽셀 아트) |
| `docs/` | 정의, 코디네이터 설계, ADR, 하네스 역할 문서 |
| `scripts/check.js` | CI 검사 (JS 문법, `index.html`의 로컬 참조, 스프라이트 20장) |
| `.github/workflows/ci.yml` | Node 24에서 `scripts/check.js` 실행 |
| `AGENT.md` | 이 저장소에서 작업하는 코딩 에이전트용 지침 |

## 검사

```bash
node scripts/check.js
```
