# Terrarium 0.2.0-beta.2 (미리보기, Windows)

0.2.0-beta.1의 고침판입니다. 바뀐 화면 설명은 [0.2.0-beta.1 릴리스 노트](v0.2.0-beta.1.md)에 있습니다. `main`에는 아직 들어가지 않았고, 설치 파일은 서명되지 않았습니다(SmartScreen: "추가 정보" → "실행").

## 고침

- 하달 직후 오퍼레이터 창의 할 일이 "이슈 없음"으로 뜨던 문제를 고쳤습니다. 이제 요청된 이슈 번호가 보입니다.

## 실제 하달로 확인한 것

앱(이 버전과 같은 코드)에서 진짜 Claude Code 코디네이터에게 "메모 예제에 `--version` 옵션 하나를 이슈 1개로 만들어 개발팀에 하달하고, 리뷰어 판정까지만 한 뒤 반영 전에 멈춰"라고 지시했습니다. 화면에는 이렇게 떴습니다.

1. 코디네이터가 부른 어드바이저 7개(패널 초안 3, 교환 3, 최종 1). 모두 끝나면 DONE.
2. 개발팀 오퍼레이터 창 하나(하달 h26). 다른 팀(디자인·테스터·기획·보안)은 뜨지 않음.
3. 그 아래 워커 창 하나(이슈 #53, 하네스가 고른 모델 gemini, 2회 시도 끝 완료).
4. Jev 리뷰어 판정, 그다음 "모든 하위 세션 완료"와 코디네이터 DONE. 코디네이터는 요청대로 반영 전에 멈춤.
5. 위쪽 사용량 칸에 실제 5시간 한도 값과 재설정 시각.

약 6분이 걸렸습니다. 시험(앱 논리 16개, 스모크 27개, 하네스 빠른·느린 시험)도 모두 통과했습니다. 자세한 기록: [docs/checks/app-screen-replace.md](../checks/app-screen-replace.md).
