# Terrarium 0.2.0-beta.3 (미리보기, Windows)

관제탑 화면 손질판입니다. 바뀐 화면 전체 설명은 [0.2.0-beta.1 릴리스 노트](v0.2.0-beta.1.md)와 [docs/app-screen.md](../app-screen.md)에 있습니다. `main`에는 아직 들어가지 않았고, 설치 파일은 서명되지 않았습니다(SmartScreen: "추가 정보" → "실행").

## 바뀜

- **Jev 표시가 실제 Jev 판정 때 켜집니다.** 어드바이저 쪽은 조언 판정 동안, 오퍼레이터 쪽은 리뷰어 판정 동안(코디네이터가 다음 일을 할 때까지)과 워커 모델을 고를 때 잠깐. 예전에는 창이 끝날 때 잠깐 켜지기만 했습니다.
- **오퍼레이터 이름이 맡은 팀입니다:** `개발 Operator`, `디자인 Operator`, `테스터 Operator`, `기획 Operator`, `보안 Operator`. 하달 번호(h<N>)는 창 안 `from Coordinator · h<N>` 줄에 있습니다. 워커 창은 그대로입니다.
- **새 지시가 와도 화면을 처음부터 다시 그리지 않습니다.** 남은 창은 그대로 있고, 새로 생긴 세션만 더해지며, 끝난 세션은 하나씩 사라집니다.
- **일이 끝난 세션은 사라집니다.** 조언이 Jev를 통과한 어드바이저, 끝난 워커, 하달이 끝나고 워커가 다 사라진 오퍼레이터는 ✓를 5초 보인 뒤 사라지고, 남은 창들이 자리를 다시 잡습니다. 다시 부르면 새로 뜹니다. 오류로 끝난 세션은 남깁니다.

## 추가

- **화면 시험 `/testgo`:** 코디네이터 터미널에 `/testgo`를 치면 3분 동안 어드바이저 3명, 다섯 팀 오퍼레이터, 한 명씩 늘어나는 워커(모두 15명), 번갈아 켜지는 Jev 표시를 보여 주고 원래 화면으로 돌아갑니다. 코디네이터에는 보내지 않고, 모델·GitHub를 부르지 않으며, 실행 폴더에 아무것도 쓰지 않습니다.
