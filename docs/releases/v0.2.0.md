# Terrarium 0.2.0 — 첫 정식 릴리스 (Windows)

Claude Code 에이전트를 계층으로 나눠 일을 맡기는 하네스와, 그것을 보고 다루는 데스크톱 앱입니다. 0.1.0은 GitHub에 릴리스하지 않았고, 그 내용(하네스)이 이 버전에 함께 들어 있습니다. 쓰기 전에 [알려진 한계](../known-limitations.md)를 읽어 주세요.

## 무엇인가요

사용자는 **코디네이터 한 명과만 대화**하고, 결과는 아래 순서로 올라옵니다.

1. 코디네이터가 요구를 정리해 GitHub 이슈로 쪼개고, 역할 오퍼레이터(개발·디자인·테스터·기획·보안)에게 하달합니다.
2. 오퍼레이터가 이슈를 워커(Pi로 claude·gemini·muse)에게 맡기고 결과를 합쳐 보고서를 씁니다.
3. 리뷰어(Jev)가 보고서를 허용하거나 거부합니다.
4. 코디네이터가 완료 기준과 대조해 사용자에게 보고합니다.
5. **사용자가 승인해야만** 대상 프로젝트의 `main`이 바뀝니다.

## 들어 있는 것

- **하네스(`harness/`):** 역할별 규칙과 스킬, 허용 명령·비밀값 보호 훅, 판정 기록, 시작 잠금(워커 계정·Jev 키가 없으면 시작하지 않음), GitHub Actions 흐름(이슈 PR → 하달 PR → CI → 사용자 승인 뒤 머지 트레인, 원격이 없으면 로컬 흐름). CLI로도 씁니다.
- **데스크톱 앱(ADR 0013):**
  - **관제탑:** 가운데 코디네이터 창에 진짜 Claude Code 터미널이 뜹니다. 그 둘레에는 코디네이터가 실제로 부른 세션만 뜹니다(어드바이저, 하달 하나당 그 팀 이름의 오퍼레이터, 워커를 부른 이슈당 워커). 일이 끝나면 사라지고 다시 부르면 새로 뜹니다. 새 지시가 와도 화면을 다시 그리지 않고, JEV 표시는 실제 판정 때 켜집니다.
  - **위쪽 칸:** 사용량(코디네이터 statusline). 사용량 단추를 누르면 계정별 한도 창이 열립니다(Claude·GitHub는 막대, Pi·Gemini·Jev는 연결 상태). 칸은 창 크기나 해상도가 바뀌어도 화면 안에 남습니다.
  - **설정 화면:** 계정 연결, 사전 점검, 실행 폴더 설치, 진행 기록. API 키는 이 컴퓨터의 암호화 저장소에만 둡니다.
  - **자동 업데이트:** 새 버전이 나오면 앱이 알려 주고 뒤에서 받습니다. [지금 재시작]이나 앱을 닫을 때 깔립니다. 다시 설치하지 않아도 됩니다.
  - 세션이 도는 중 창을 닫으면 경고하고, 화면 시험 `/testgo`가 있습니다.

전체 목록은 [CHANGELOG](../../CHANGELOG.md)의 0.2.0과 그 미리보기들(beta.1~5)에 있습니다.

## 설치

- **앱:** 이 릴리스의 `Terrarium-Setup-0.2.0.exe`를 받아 실행합니다.
  - 코드 서명이 없어 Windows가 "Windows의 PC 보호" 경고를 띄웁니다. **추가 정보 → 실행**을 누르세요.
  - 0.2.0-beta.4 이상을 쓰고 있으면 다시 설치하지 않아도 됩니다. 앱이 업데이트를 알려 줍니다.
- **CLI:** [README의 "Claude CLI 버전"](../../README.md)을 따릅니다.

**두 방법 모두 필요한 것:** Node 22 이상, git, GitHub CLI 로그인(`gh auth login`)과 비공개 지정 저장소, Claude Code 로그인, 워커 모델 계정 1곳 이상(Pi), TypeSafe Jev 키(`TYPESAFE_API_KEY`).

## 확인

- 하네스 시험(빠른·느린)과 `scripts/check.js`: CI 통과.
- 앱: 논리 시험 27개, 스모크 39개(진짜 앱 창, 가짜 코디네이터).
- 12개 시나리오 점검표를 실제 모델로 돌림(`docs/checks/T13-scenarios.md`, 소유자 확인).
- 깨끗한 Windows 계정(샌드박스)에서 설치·실행(#41), 설치판 beta.4 → beta.5 자동 업데이트(소유자 확인).

## 알려진 한계

- **판정을 꾸밀 수 있음:** 같은 `gh` 계정이면 리뷰어 판정을 꾸밀 수 있습니다.
- **샌드박스 없음:** 워커에는 OS 샌드박스가 없습니다(사후 검사와 리뷰어가 막습니다).
- **리뷰어가 한 곳에 달림:** 리뷰어와 라우팅이 Jev 한 곳에 달려 있습니다.
- **Windows에서만 확인:** 실제 실행은 Windows에서만 했습니다. CI는 ubuntu에서 시험을 돕니다.
- **한국어 전용:** 프로토콜(역할 문서, 이슈 양식, 판정 문구)이 한국어입니다.
- **업데이트 범위:** 앱 업데이트로 훅·실행 스크립트는 바뀌지만, 실행 폴더에 복사된 규칙(`CLAUDE.md`, `.claude/`)은 `setup --refresh`로 다시 써야 합니다.
