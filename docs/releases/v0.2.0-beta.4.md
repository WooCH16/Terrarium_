# Terrarium 0.2.0-beta.4 (미리보기, Windows)

업데이트 알림을 넣은 판입니다. 바뀐 화면 전체 설명은 [docs/app-screen.md](../app-screen.md)에 있습니다. `main`에는 아직 들어가지 않았고, 설치 파일은 서명되지 않았습니다(SmartScreen: "추가 정보" → "실행").

**이번 한 번은 직접 설치하세요.** 0.2.0-beta.3 이하에는 업데이트 기능이 없습니다. 이 판부터는 다음 버전이 나오면 앱이 알려 주고, 다시 설치하지 않고 업데이트됩니다.

## 추가

- **업데이트 알림:** 앱을 켜고 10초 뒤와 6시간마다 새 버전을 확인합니다. 있으면 뒤에서 받으며 관제탑 위쪽에 알림을 띄웁니다. 다 받으면 **[지금 재시작]**(바로 깔고 다시 켬) 또는 **[나중에]**(앱을 닫을 때 깔림)를 고릅니다. 세션이 도는 중에 [지금 재시작]을 누르면 "진행중인 세션이 있습니다." 경고가 먼저 뜹니다. 설정(`%APPDATA%\Terrarium`)은 그대로 남고, 실행 폴더에 설치된 하네스 파일은 바뀌지 않습니다.
- **창 닫기 경고:** 세션이 도는 중에 창을 닫으면 "진행중인 세션이 있습니다."와 [확인]·[돌아가기]를 띄웁니다.

## 없앰

- 관제탑 오른쪽 위의 프로필 단추와 계정 팝업. 계정 관리·진행 기록은 톱니 → [설정 열기]에서 엽니다.

## 고침

- 하네스가 기록에 한 줄을 쓰는 도중에 앱이 읽으면, 그 줄(예: 어드바이저 호출)이 완성된 뒤에도 화면에서 빠지던 문제.
- 관제탑 흐름이 기록 파일과 끝난 하달 폴더를 1초마다 처음부터 다시 읽던 낭비(긴 실행에서 한 번 읽기 약 59ms → 0.3ms). 쉬는 배경 캔버스를 매 프레임 다시 그리던 것도 멈춥니다.

## 확인

앱 논리 시험 25개, 스모크 37개(진짜 앱 창, 가짜 코디네이터), 하네스 빠른 시험이 모두 통과했습니다.
