# Terrarium 0.2.0-beta.1 (미리보기, Windows)

`beta` 브랜치의 미리보기입니다. `main`에는 아직 들어가지 않았습니다. 설치 파일은 서명되지 않아 Windows SmartScreen이 경고할 수 있습니다("추가 정보" → "실행").

## 무엇이 바뀌었나

앱의 관제탑 화면이 새 디자인으로 바뀌었습니다.

- 가운데 **코디네이터 창** 안에 진짜 Claude Code 코디네이터 터미널이 뜹니다. 지시는 여기에 직접 칩니다.
- 코디네이터가 실제로 부른 세션만 둘레에 창으로 뜹니다.
  - 오른쪽: 어드바이저(부를 때마다 하나)
  - 아래: 하달 한 번당 오퍼레이터 창 하나(팀 이름: 개발·디자인·테스터·기획·보안)
  - 그 아래: 그 하달에서 워커를 부른 이슈당 워커 창 하나(모델은 하네스가 고른 값)
  - 하달하지 않은 팀이나 하달에 없는 이슈는 뜨지 않습니다.
- 배경을 끌어 이동, 휠로 확대·축소, 창은 머리줄로 옮기고 가장자리로 크기를 바꿉니다. 오퍼레이터 창을 두 번 누르면 그 하달의 워커와 모델이 보입니다.
- 위쪽 칸: 실행 폴더 단추와 탭, 실제 사용량(코디네이터 statusline의 5시간·주간 한도와 컨텍스트, Claude Pro·Max 구독에서 첫 응답 뒤에 보임), GitHub 계정·지정 저장소·사전 점검, 설정 화면(계정·설치·진행 기록)으로 가는 단추.
- 화면은 실행 폴더의 기록을 읽기만 합니다. 자세한 내용: [docs/app-screen.md](../app-screen.md).

## 빠진 것

예전 관제탑의 오른쪽 폴더 패널, 팀 상세·통합·사무실 보기, 다섯 자리 역할 카드, 브라우저 미리보기는 이번 화면에 없습니다. 하달·이슈 진행은 설정 화면의 진행 기록 탭에 있습니다.

## 설치와 처음 쓰기

필요한 것과 처음 쓰는 순서는 0.1.0과 같습니다: [README](../../README.md)의 "1. 앱 버전". 설정 화면은 오른쪽 위 톱니 → [설정 열기]에서 엽니다.

## 확인한 것

- 앱 논리 시험 16개, 스모크 시험 27개(진짜 앱 창 + 가짜 코디네이터, 모델·네트워크 안 씀), 하네스 빠른 시험·느린 시험, CI 검사.
- 설치본을 임시 앱 데이터로 띄워 화면·터미널·글꼴이 읽히는지, 설치본 안에 개인 경로·계정·비밀값이 없는지 확인했습니다.
- 실제 모델로 하달하는 종단 시험은 이번 미리보기에서 돌리지 않았습니다.
