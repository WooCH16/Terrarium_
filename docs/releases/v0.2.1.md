# Terrarium 0.2.1 (Windows)

0.2.0의 작은 업데이트입니다. 앱의 고친 것 두 가지와 하네스의 새 기능이 들어 있습니다. 전체 목록은 [CHANGELOG](../../CHANGELOG.md)의 0.2.1에 있습니다.

## 고침 (앱)

- 코디네이터 터미널의 링크를 누르면 영어 경고 창이 뜨고 열리지 않던 문제. 이제 http·https 주소를 기본 브라우저로 바로 엽니다.
- 코디네이터 창 아래 기록 줄에 마우스 위치 글씨(`<35;74;15M…`)가 쌓이던 문제.

## 바뀜 (하네스)

- **워커는 고르지 않고 묻습니다(결정 8-38):** 이슈가 정하지 않은 갈림길에서 워커는 질문을 남기고 멈춥니다(종료 코드 4). 오퍼레이터가 답하면 같은 작업에서 이어 갑니다. 답을 받지 못한 이슈는 합치지 않습니다.
- **Pi 워커 확장(결정 8-39):** Pi 워커는 `ask_operator` 도구로 묻고, 답을 기다렸다가 같은 세션에서 이어 갑니다. 새 패키지 설치, 시험 지우기, `package.json` 의존성 더하기는 훅이 실행 전에 막고 허용 여부를 묻습니다. 오퍼레이터에게는 종료 코드 5(`질문 중`)로 알립니다.
- **워커 동시 실행:** 서로 기대지 않는 이슈의 워커를 최대 3개까지 함께 돌립니다(`run-worker --detach yes`, `wait-operator`).
- **정리:** 끝난 하달의 작업 폴더와, 모두 반영된 하달의 브랜치를 지웁니다.

## 설치

- 0.2.0을 설치판으로 쓰고 있으면 다시 설치하지 않아도 됩니다. 앱이 업데이트를 알려 줍니다.
- 새로 설치하려면 이 릴리스의 `Terrarium-Setup-0.2.1.exe`를 받아 실행합니다. 코드 서명이 없어 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 알려진 한계

- Pi 워커 확장으로 진짜 하달을 처음부터 끝까지 돌려 본 확인은 아직 없습니다. 실제 Pi 1.5.1에서 묻기·답 받기·설치 막기만 확인했습니다.
- 훅은 도구 호출만 봅니다. claude·agy CLI 워커에는 붙지 않습니다.
- 나머지는 [알려진 한계](../known-limitations.md)를 보세요.
