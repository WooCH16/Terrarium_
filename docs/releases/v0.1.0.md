# Terrarium v0.1.0 — 첫 공개 미리보기 (Windows 우선)

> 미리보기 버전입니다. 개인용 하네스를 공개한 첫 버전이라 거친 부분이 있습니다. 쓰기 전에 [알려진 한계](../known-limitations.md)를 꼭 읽어 주세요.

## 무엇인가요

Claude Code 에이전트를 계층으로 나눠 일을 맡기는 하네스입니다. 사용자는 **코디네이터 한 명과만 대화**하고, 결과는 아래 순서로 올라옵니다.

1. 코디네이터가 요구를 정리해 GitHub 이슈로 쪼개고, 역할 오퍼레이터(개발·디자인·테스터·기획·보안)에게 하달합니다.
2. 오퍼레이터가 이슈를 워커(Pi로 claude·gemini·muse)에게 맡기고 결과를 합쳐 보고서를 씁니다.
3. 리뷰어(Jev)가 보고서를 허용하거나 거부합니다.
4. 코디네이터가 완료 기준과 대조해 사용자에게 보고합니다.
5. **사용자가 승인해야만** 대상 프로젝트의 `main`이 바뀝니다.

## 이 버전에 들어 있는 것

- **데스크톱 앱 (Windows):** 관제탑 화면과 코디네이터 터미널.
  - 설정 화면에서 계정 연결, 사전 점검, 실행 폴더 설치, 진행 기록을 다룹니다.
  - API 키는 이 컴퓨터의 암호화 저장소에만 둡니다.
- **CLI:** 저장소를 받아 `preflight.mjs` → `setup.mjs` → 실행 폴더에서 `claude`. Node만 있으면 되고 다른 의존성은 없습니다.
- **GitHub Actions 흐름:** 대상 프로젝트에 원격과 하네스 워크플로가 있으면 이렇게 돕니다.
  - 이슈 PR → 하달 PR → CI → 머지 트레인 순서입니다.
  - 트레인은 사용자 승인 뒤에만 돕니다.
  - 원격이 없으면 로컬 흐름으로 돕니다.
- **안전 장치:** 역할별 허용 명령과 비밀값 보호 훅, 판정 기록, 시작 잠금(워커 계정·Jev 키가 없으면 시작하지 않음).

전체 목록은 [CHANGELOG](../../CHANGELOG.md)에 있습니다.

## 설치

- **앱:** 이 릴리스의 `Terrarium Setup 0.1.0.exe`를 받아 실행합니다.
  - 코드 서명이 없어 Windows가 "Windows의 PC 보호" 경고를 띄웁니다. **추가 정보 → 실행**을 누르세요.
- **CLI:** [README의 "Claude CLI 버전"](../../README.md)을 따릅니다.

**두 방법 모두 필요한 것:**
- Node 22 이상, git
- GitHub CLI 로그인(`gh auth login`)과 비공개 지정 저장소
- Claude Code 로그인
- 워커 모델 계정 1곳 이상(Pi)
- TypeSafe Jev 키(`TYPESAFE_API_KEY`)

## 알려진 한계

- **판정을 꾸밀 수 있음:** 같은 `gh` 계정이면 리뷰어 판정을 꾸밀 수 있습니다.
- **샌드박스 없음:** 워커에는 OS 샌드박스가 없습니다(사후 검사와 리뷰어가 막습니다).
- **리뷰어가 한 곳에 달림:** 리뷰어와 라우팅이 Jev 한 곳에 달려 있습니다.
- **Windows에서만 확인:** 실제 실행은 Windows에서만 했습니다. CI는 ubuntu에서 단위·통합 시험을 돕니다.
- **한국어 전용:** 프로토콜(역할 문서, 이슈 양식, 판정 문구)이 한국어입니다.
