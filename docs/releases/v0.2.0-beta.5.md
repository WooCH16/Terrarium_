# Terrarium 0.2.0-beta.5 (미리보기, Windows)

관제탑 손질판입니다. 바뀐 화면 전체 설명은 [docs/app-screen.md](../app-screen.md)에 있습니다. `main`에는 아직 들어가지 않았고, 설치 파일은 서명되지 않았습니다(SmartScreen: "추가 정보" → "실행").

**0.2.0-beta.4를 쓰고 있으면 다시 설치하지 않아도 됩니다.** 앱을 켜면 위쪽에 업데이트 알림이 뜨고, 다 받으면 [지금 재시작]으로 깔립니다. beta.3 이하는 이 설치 파일을 한 번 직접 실행하세요.

## 추가

- **계정별 한도 창:** 위쪽 사용량 단추를 누르면 연결된 계정마다 한도를 보입니다. Claude(5시간·주간 한도, 코디네이터 컨텍스트)와 GitHub(API 남은 횟수)는 막대로, Pi(anthropic·meta)·Gemini·Jev는 연결 상태를 보입니다. 이 넷은 제공사가 남은 한도를 알려 주지 않아 그렇게 적습니다.

## 바뀜

- **흰 제목 표시줄을 없앴습니다.** 창 단추(최소화·최대화·닫기)만 배경색 위 오른쪽 위에 남고, 위쪽 32px를 끌어 창을 옮깁니다.
- **사용량이 곧 보입니다.** 코디네이터가 답하면 3초 안에 사용량이 바뀝니다(전에는 30초까지 걸려 "사용량 모름"으로 남아 있었음). 첫 답 전에는 "첫 답 뒤 표시".

## 고침

- 하달·조사를 분리 실행할 때 드물게 "결과 없이 끝남"(종료 코드 2)으로 잘못 보던 경쟁 상태를 고쳤습니다.

## 확인

앱 논리 시험 27개, 스모크 38개(진짜 앱 창, 가짜 코디네이터), 하네스 빠른 시험이 모두 통과했습니다.
