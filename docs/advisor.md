# 어드바이저 설계

- 실행 문서: [`harness/advisor/AGENT.md`](../harness/advisor/AGENT.md) (설치하면 실행 폴더의 `.claude/agents/advisor.md`)
- 결정: ADR 0002(조언을 리뷰어가 거른다), ADR 0006(어드바이저가 리뷰어를 직접 부른다), ADR 0008(리뷰어는 Jev). 이슈 #42, 소유자 위임 8-11, 결정 8-15
- 이 문서는 옛 `docs/harness/advisor.md`를 넓힌 것이다.

## 1. 개요

어드바이저는 "작업을 어떻게 나눌지"를 제안문으로 쓰는 역할이다. 코디네이터가 부르는 **Claude Code 하위 에이전트**(`subagent_type: advisor`)다. 조언만 하고, 이슈 등록과 하달은 코디네이터가 한다.

제안문은 리뷰어(Jev)의 허용을 받아야 코디네이터에게 간다. 조언이 틀리면 그 뒤의 이슈가 모두 틀어지므로, 영역 판단을 하지 않는 코디네이터 대신 리뷰어가 조언 단계에서 한 번 거른다(ADR 0002).

## 2. 하는 일과 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 대상 프로젝트를 읽기 도구로 읽기 | 대상 프로젝트 고치기, 실행하기 |
| 작업 단위로 나눈 제안문을 `reviewer-inbox/<조언 id>.md`에 쓰기 | 다른 곳에 쓰기 |
| `run-reviewer.mjs --advice … --advice-id <id>`로 판정받기, 거부면 같은 id로 한 번 고쳐 다시 받기 | 스스로 조언 id 만들기, 판정 줄 고쳐 쓰기 |
| 자료가 모자라면 `자료 요청: <영역> / <질문>` 한 줄 돌려주기 | 직접 깊은 조사(오퍼레이터의 조사 이슈로 한다) |

## 3. 입력과 출력

- **입력(코디네이터가 넘김):** 사용자 지시 원문, 대상 프로젝트 경로, 코디네이터가 정한 조언 id, (있으면) 조사 결과 파일 경로.
- **제안문 양식:** `## 작업 단위 …` 절마다 `### 목표`, `### 완료 기준`(`| 기준 | 확인 방법 |` 표), `### 먼저 끝나야 할 것`, `### 전제·위험`. 리뷰어 코드가 글자까지 검사한다.
- **출력:** 판정 스크립트의 출력 줄을 그대로 돌려준다. 허용 줄에는 `허용된 조언: <64자리>`, `전달 파일: <경로>`, `조언 id: <id>`가 있다.

## 4. 작업 단위 나누기 (결정 8-15)

- 단위 하나는 **작은 모델도 이슈 글만 보고 한 번에 끝낼 수 있는 크기**다. 고칠 파일과 기대 동작을 이름으로 적을 수 있어야 하고, 넘으면 더 나눈다.
- 서로 다른 파일·관심사는 다른 단위로 나눈다. 핵심 로직과 그것을 쓰는 진입점이 둘 다 바뀌면 두 단위로 나누고 순서를 "먼저 끝나야 할 것"에 적는다.
- 문서·예시만 바꾸는 일은 코드 단위와 따로 둔다. 지시에 없는 일을 더하지 않는다.

## 5. 판정과 한도

- 판정은 [reviewer.md](reviewer.md)의 조언 판정이다. 같은 조언 id는 **2번까지만** 판정받는다. 2번째도 거부되면 스크립트가 종료 코드 7로 끝나고, 코디네이터가 기록된 해시와 거부 이유로 사용자에게 묻는다.
- **조언 id 우회 막기:** 코디네이터는 돌아온 허용 줄의 `조언 id`와 `advice-log.jsonl`에 기록된 그 해시 줄의 `adviceId`가 자기가 넘긴 id인지 확인한다. 다른 id로 받은 허용은 쓰지 않는다.

## 6. 실행과 안전

- **모델:** 코디네이터와 같은 급(`model: inherit`). 분해가 틀리면 워커·리뷰어 비용이 전부 낭비되므로 여기서 아끼지 않는다.
- **도구:** Read, Grep, Glob, Write, Bash. 훅이 쓰기는 `reviewer-inbox/`로, 명령은 `run-reviewer.mjs --advice` 한 모양으로 막는다(ADR 0006 결정 2).
- **시험용 대역:** `setup --advisor-stub`은 `harness/stubs/advisor-stub.md`를 대신 설치한다.

## 7. 한계

- v0의 어드바이저는 대상 프로젝트 전체를 맡는 **하나**다. 훅이 하위 에이전트 이름 `advisor` 하나만 받고, 하위 에이전트끼리는 말할 수 없어 overview 2.3의 "영역별 어드바이저, 겹치면 모두 부르고 협의"는 v1로 미룬다.
