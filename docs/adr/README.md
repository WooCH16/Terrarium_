# ADR 색인

이 문서가 **현재 유효한 ADR의 유일한 목록**이다. 코디네이터와 새 세션은 여기서 상태가 "채택됨"인 ADR만 읽는다. `docs/history/`는 사람이 직접 확인하려고 만든 이력 문서이므로 읽지 않는다.

| 번호 | 제목 | 상태 | 대체한 ADR | 대체된 결정 |
|---|---|---|---|---|
| [0001](0001-harness-shape.md) | 하네스의 형태: 역할, 실행, 소통, 권한, 환경 | 채택됨 | - | 결정 1, 2 (→ 0002), 결정 3의 조사 예외 (→ 0003 대체됨) |
| [0002](0002-reviewer-gates-advice.md) | 리뷰어가 어드바이저 조언도 허용/거부하고, 첫 버전은 하위 역할을 하위 에이전트로 부른다 | 채택됨 | 0001 결정 1, 2 | 결정 B의 오퍼레이터·워커 부분, 결정 A의 조사 경로 (→ 0003 대체됨) |
| [0003](0003-operator-harness.md) | 오퍼레이터 하네스: 독립 세션, 합치기·보고 담당, 머지 큐 CI, 안전과 격리 | 채택됨 | 0002 결정 B의 오퍼레이터·워커 부분, 0001·0002의 조사 경로 | 결정 A의 워커 실행 방식 (→ 0004 대체 예정) |
| [0004](0004-pi-worker-reviewer.md) | 워커와 리뷰어는 Pi 하네스로 실행, 리뷰어는 워커와 다른 타입의 모델(Claude, Gemini, Muse)을 번갈아 사용, 모델 상세, `codex` 제외 | 제안됨 | 0002 결정 B의 리뷰어 실행 방식, 0003 결정 A의 워커 실행 방식 (대체 예정) | - |

## 규칙

- 번호는 `0001`, `0002`처럼 올리고 `docs/adr/` 아래에 쌓는다.
- 상태는 "제안됨", "채택됨", "대체됨" 세 가지다. **"제안됨"은 사용자 승인 전이며 에이전트는 읽지 않는다.** 승인되면 "채택됨"으로 바꾸고, 그 ADR이 대체하는 결정에 달린 "대체 예정" 표시를 "대체됨"으로 바꾼다.
- 결정을 바꿀 때는 옛 ADR을 고치지 않고 **새 ADR을 쓴다.** 새 ADR에 "0001의 결정 N을 대체한다"고 쓴다.
- 대체된 ADR은 지우지 않는다. 문서 맨 위와 대체된 결정 바로 아래에 "대체됨 → 새 ADR 번호와 결정" 경고를 단다.
- 일부 결정만 대체되면 한 ADR 안에서 결정 단위로 "유효 / 대체됨"을 표시하고, 이 색인의 "대체된 결정" 칸에 번호를 적는다.
- ADR을 대체하면 **이 색인과 경고 문구를 같은 작업에서 함께 고친다.**
- `docs/overview.md`는 현재 유효한 ADR 번호만 가리킨다.
