# ADR 0007. Muse 공개 제한은 실행 폴더의 로컬 설정으로 끈다

- 상태: **채택됨**
- 날짜: 2026-11-19 (같은 날 고침: 공개 기본값은 제한을 켜 두고, 소유자 결정 8-6은 로컬 설정으로 옮김. 오픈소스 v0 0단계)
- 대체: **[ADR 0006](0006-advice-verdict.md) 결정 6의 "Muse에는 공개해도 되는 제안문만 넘긴다"와 소유자 결정 5-3의 "muse로 대체되는 것은 `공개 가능: 예`인 이슈만"을, 실행 폴더에 로컬 설정이 있을 때에 한해 대체한다.** 로컬 설정이 없으면 두 결정이 그대로 유효하다. 리뷰어를 어드바이저·워커와 다른 타입으로 번갈아 쓰는 규칙, 대체 표(claude → gemini → muse → claude)는 유효하다.
- 범위: 워커 모델 대체, 결과 보고서 판정, 조언 판정에서 Muse로 넘기는 내용의 제한.

## 배경

Muse Spark 1.3은 Contributor 등급이라 보낸 입력이 학습에 쓰일 수 있다([ADR 0004](0004-pi-worker-reviewer.md)). 그래서 공개해도 되는 내용만 Muse에 넘기도록 `공개 가능: 예` 표시와 설정의 `runners.muse.publicOnly`를 두었다. #14 T11 첫 한 바퀴에서 결과 판정 경로에 이 검사가 빠져 비공개 이슈가 Muse로 판정된 일이 있었고, 고친 뒤 소유자에게 확인했다.

## 결정

- 소유자는 비공개 내용(이슈 본문, 제안문, 결과 보고서, 대상 프로젝트 코드)이 Muse에 들어가도 된다고 정했다(소유자 결정 8-6, 2026-11-19).
- 공개 기본 설정 `harness/operator/operator.config.json`은 `runners.muse.publicOnly: true`로 둔다. 저장소를 받아 쓰는 다른 사람의 비공개 내용이 학습될 수 있는 등급으로 넘어가지 않게 하려는 것이다(오픈소스 v0, `docs/checks/open-source-v0.md` 0단계).
- 소유자 결정 8-6은 실행 폴더의 `operator.local.json`에 둔다: `{ "runners": { "muse": { "publicOnly": false } } }`. 이 파일은 git에 없고, 모든 역할의 훅이 쓰기를 막는다. 덮어쓸 수 있는 것은 `runners.<모델>.publicOnly` 하나뿐이다(그 밖의 키나 모양은 설정 오류).
- 설정을 읽는 모든 스크립트(`run-operator`, `run-research`, `run-worker`, `run-reviewer`, 합치기·반영)가 실행 폴더의 로컬 설정을 덮어쓴다. 워커 대체, 결과 판정, 조언 판정 세 경로가 같은 값을 본다(조언 판정도 `muse` 고정이 아니라 설정을 본다).
- 이슈 양식의 `공개 가능` 칸은 남긴다. 제한이 켜진 실행 폴더에서 쓰인다.

## 이유

- 소유자의 실행 폴더에서는 리뷰어 순환이 공개 표시 때문에 gemini 하나로 쏠리지 않고, 대체 표가 막힘 없이 한 바퀴 돈다.
- 소유자의 선택은 그 컴퓨터의 일이라 공개 기본값에 넣지 않는다. 받는 사람은 안전한 쪽에서 시작하고, 원하면 스스로 끈다.

## 검토한 대안

- 장치와 `공개 가능` 칸을 모두 지우는 안: 코드가 줄지만 제한을 다시 켤 수단이 없어진다. 소유자가 비공개 내용을 허용한 것은 이 사용 환경의 결정이라 기각했다.
- 공개 기본값을 `false`로 두는 안(이 ADR의 처음 판): 받는 사람이 모르는 채 비공개 내용을 넘기게 되어 기각했다.
- 로컬 설정을 `harness/operator/` 안에 두는 안: 저장소 안이라 시험이 소유자 컴퓨터에서만 다르게 돌고, 실수로 커밋될 수 있어 실행 폴더에 두었다.

## 확인

- `harness/test/operator-config.test.mjs`: 로컬 설정이 `publicOnly`만 덮어쓰고 다른 키·모양은 설정 오류인지.
- `harness/test/run-worker.test.mjs`, `run-reviewer.test.mjs`, `operator-runners.test.mjs`: 공개 기본 설정은 공개 표시 없는 내용을 Muse에 넘기지 않고, 실행 폴더에 로컬 설정이 있으면 넘기는지.
- `harness/test/policy.test.mjs`: 모든 역할이 `operator.local.json`을 쓸 수 없는지.
