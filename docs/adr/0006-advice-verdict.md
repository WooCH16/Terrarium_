# ADR 0006. 조언 판정은 리뷰어 전용 폴더에서 하고, 어드바이저가 리뷰어를 직접 부른다

- 상태: **채택됨**
- 날짜: 2026-11-18
- 대체: **[ADR 0002](0002-reviewer-gates-advice.md) 결정 A의 "조언이 거부되면 코디네이터가 거부 이유와 함께 어드바이저에게 되돌려 수정하게 한다"와 결정 B의 "조언에 대한 판정은 하위 에이전트가 바로 돌려준다"를 대체한다.** 리뷰어의 두 기능, 허용된 조언만 이슈로 만든다는 규칙은 유효하다.
- 범위: 조언 판정의 형식, 실행 수단, 전달 경로. 결과 보고서 판정(ADR 0004)은 바꾸지 않는다.
- **일부 대체됨 → [ADR 0007](0007-muse-no-public-gate.md): 결정 6의 "Muse에는 공개해도 되는 제안문만 넘긴다"는 실행 폴더에 로컬 설정이 있으면 꺼진다(소유자 결정 8-6). 공개 기본값은 그대로다.**

## 배경

결과 보고서 판정의 허용 형식은 `허용된 커밋: <40자리 해시>`이다. 조언 단계에는 이슈도 커밋도 없어서 이 형식을 쓸 수 없고, 조언 판정을 실행할 수단도 없었다. 그래서 직접 지시 경로 5번이 멈추고, #14 T11 첫 한 바퀴와 시나리오 4, 12를 돌릴 수 없었다.

## 결정

1. 어드바이저는 논의된 제안문을 **리뷰어 전용 폴더**에 문서로 쓴다.
2. 어드바이저가 `node harness/operator/run-reviewer.mjs --advice <제안문 파일>`로 리뷰어를 **직접** 부른다. 어드바이저에게 허용하는 실행 명령은 이것 하나뿐이고, 쓰기는 리뷰어 전용 폴더에만 허용한다. 나머지는 훅이 막는다.
3. 리뷰어 모델은 제안문을 읽고 판정만 한다(읽기 전용, ADR 0004 결정 C). 판정 형식은 다음과 같다.
   - 허용: `## 리뷰어 판정: 허용` 아래에 `허용된 조언: <제안문 SHA-256 64자리>` 한 줄. 이 형식이 아니거나 해시가 다르면 거부로 처리한다.
   - 거부: 첫 줄 `## 리뷰어 판정: 거부`, 다음 줄부터 이유.
4. 파일을 옮기거나 지우는 일은 리뷰어 모델이 아니라 **스크립트**가 한다. 스크립트는 제안문의 해시와 판정(거부면 이유까지)을 실행 기록에 남긴 뒤 다음을 한다.
   - 거부: 이유를 어드바이저에게 돌려주고 폴더의 제안문을 지운다.
   - 허용: 제안문을 코디네이터에게 넘기고 폴더의 제안문을 지운다. 코디네이터는 허용된 해시를 이슈 근거 칸에 적는다.
5. 같은 조언은 **2번까지만** 판정받는다. 2번째도 거부되면 스크립트가 더 받지 않고 코디네이터에게 알리며, 코디네이터가 기록된 해시와 거부 이유를 근거로 사용자에게 묻는다.
6. 조언 판정 리뷰어는 어드바이저와 다른 타입(어드바이저가 Claude이면 `gemini`, `muse`)을 번갈아 쓴다. Muse는 Contributor 등급이라 입력이 학습에 쓰일 수 있으므로 **공개해도 되는 제안문만** 넘긴다. **(일부 대체됨 → ADR 0007: 실행 폴더의 `operator.local.json`으로 끌 수 있다. 공개 기본값은 이 결정 그대로다.)**

## 이유

- 조언 단계에는 이슈가 없으므로 판정을 이슈 댓글 대신 폴더와 실행 기록에 둔다. 해시로 묶으면 리뷰어가 본 제안문과 이슈로 옮긴 제안문이 같은지 커밋 해시처럼 기계적으로 대조할 수 있다.
- 어드바이저가 리뷰어를 직접 부르면 코디네이터를 거치는 단계가 줄고, 수정과 재판정 고리가 코디네이터의 컨텍스트를 채우지 않는다.
- 어드바이저 안에서 고리가 돌기 때문에 반복 한도는 어드바이저가 아니라 스크립트가 지킨다.
- 제안문을 지워도 해시와 판정 기록이 남아 2회 거부 뒤 사용자에게 근거를 보여줄 수 있다.

## 검토한 대안

- 코디네이터가 리뷰어를 띄우는 안: 기존 권한 그대로 되지만 고리마다 코디네이터를 거쳐 호출과 컨텍스트가 늘어 기각했다.
- 해시 없이 허용/거부 한 줄만 보는 안: 단순하지만 판정 뒤 바뀐 제안문을 잡지 못해 기각했다.
- Muse를 조언 판정에서 빼는 안: 비공개 노출 위험은 없지만 리뷰어가 gemini 하나만 남아 순환이 없어지므로, 공개 가능한 제안문만 넘기는 조건으로 포함했다.
