## 컴팩션 메모 (시나리오 10)

- `docs/checks/T0-preflight.md` 1번: Claude Code 공식 문서에 `PreCompact` 훅 이벤트가 있다(문서로 확인). **실제로 발화하는지는 확인되지 않았다.**
- 이 하네스의 설정(`setup.mjs`가 쓰는 `.claude/settings.json`)에는 `PreToolUse` 훅만 있고 `PreCompact` 훅은 없다. 훅은 더하지 않았다.
- 그래서 overview 5.2의 "컴팩션 직전" 갱신 시점은 문구대로 옮겼지만, 지금 하네스에서 그 신호를 받는 장치는 없다. 실제 발화 확인은 T0 문서가 적은 대로 #14 T11 또는 #16 T13(시나리오 10)의 몫이다. 기능이 없다고 판명되면 이슈 #13의 전제대로 "에이전트가 정한 시점에 보존 노트를 쓴다"로 바뀐다.
- 5.2 "앞" 구간의 파일(`AGENT.md`, `docs/`)은 Terrarium 저장소의 파일이다. 코디네이터 실행 폴더에는 이 파일들이 없고 규칙은 `CLAUDE.md`다. 실행 폴더에서 무엇을 다시 읽을지는 overview에 없어 미결이다.
- 보존 노트와 선호 문서의 파일 이름은 overview에 없어 정하지 않았다.

## 이 작업으로 채워지지 않는 조건

- 이슈 #13 끝나는 조건 3("문서 사이의 충돌은 사용자 답을 받은 것만 반영했다"): 2026-11-18 소유자 답을 받아 충돌 4가지를 모두 반영했다.

- 시나리오 10의 "컴팩션 직전" 갱신은 신호를 받는 장치가 없다.
