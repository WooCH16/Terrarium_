# 하네스 오픈소스 v0 계획

2026-11-19에 어드바이저 조언으로 방향을 잡고, 소유자 결정 네 가지를 받아 정했다. 1~5단계 항목은 GitHub 이슈 #19~#43(라벨 `오픈소스 v0`)으로 만들었다. 소유자 결정이 필요한 이슈에는 `소유자 결정 필요` 라벨을 붙였다.

**v0 완료 기준:** 다른 사람이 데스크톱 앱을 설치해 계정 2개 이상(워커 모델 1곳 이상과 TypeSafe의 Jev, 결정 9-3 바뀜)과 GitHub를 연결하고, 자기 비공개 저장소와 자기 대상 프로젝트를 지정한 뒤, 직접 지시 한 건이 한 바퀴 돌아 `verify.mjs`의 일반 검사를 통과한다.

## 소유자 결정

| 9-6 | 계정 연결 방식 | **둘 다 지원.** 기본은 각 CLI의 로그인(`claude`, `agy`, `pi`, `gh auth login`)을 앱에서 띄우고 연결 상태만 보여 준다. CLI 로그인이 없는 제공사만 API 키를 받아 운영체제 보안 저장소에 둔다. 워커 모델 계정이 하나도 없거나 Jev 키가 없으면 시작을 잠근다(9-3 바뀜) |
| 9-7 | 앱 기술 | **Electron.** 메인 프로세스(Node)가 하네스 스크립트를 직접 부르고, API 키는 `safeStorage`에 둔다. 설치 파일이 큰 것(수백 MB)은 감수한다 |
